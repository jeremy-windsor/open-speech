        History Settings

        History retention is configured on the server and takes effect after a restart.

        OS_HISTORY_ENABLED — enable or disable history.

        OS_HISTORY_MAX_ENTRIES — set the maximum retained entries.

        OS_HISTORY_RETAIN_AUDIO — keep or discard generated audio files.
