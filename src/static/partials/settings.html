AI assistant

Open Speech can send what you say, or a book, to your own AI server and read the reply aloud. An AI preset holds the prompts, the thinking controls, the limits and the sentences it speaks.

Status
Checking…

This server sets the AI connection only in its .env (OS_ASSISTANT_*), which changes with a restart.

To turn it on, enter your AI server's address under Connection, then Check and Save.

To turn it on, set OS_ASSISTANT_URL in the server's .env to your AI server's address, ending in /v1 (for example http://ai-server.lan:8080/v1), then restart Open Speech.

    Ask AI

    What Ask AI calls it, such as “Summarize”. Empty uses the default.

    Offered for

    Prompts

    Which saved assistant answers with this preset.

    The system message: how the AI should answer. Empty uses the default prompt.

    Thinking

    On or Off sends enable_thinking as a chat-template variable, for models that can think or not.

    Sent as reasoning_effort. Servers accept different values: Test shows whether yours takes this one. “Not sent” uses OS_ASSISTANT_REASONING_EFFORT when the server sets it.

    Sent as reasoning_budget_tokens, which llama.cpp-style servers read: when the thinking reaches it, the model wraps up and still writes a whole answer. 0 sends none; up to 1,000,000. Other servers ignore or refuse the field: Test shows whether yours takes it.

    Sends the AI's thinking to the app as text, when the server returns it. It's never spoken.

    Limits

    It cuts the answer off without telling the model: an answer that reaches it stops mid-sentence, and on most servers the thinking counts towards it. For a short answer, ask in the prompt (“Answer in 3 sentences.”) and keep this as a safety net. 0 sends no limit.

    How long to wait for the whole reply, 5 to 3,600.

    Earlier exchanges sent with each voice turn, 0 to 100.

    The most book text in one request, 1,000 to 200,000.

    Sampling

    Empty uses the AI server's own default. Some reasoning models refuse these.

    While waiting

    Said while a voice turn waits for the AI, in random order. Remove them all to say nothing.

      No phrases: nothing is said while it waits.

      Up to 10, of up to 80 characters.

      No phrase when the reply comes sooner.

      The gap before the next phrase while it still waits.

      Phrases in one turn, 0 to 10.

      Errors

      When the AI can't answer a voice turn, this sentence is spoken. Empty uses the default.

      Test

      Sends one message with the preset as it is on screen, saved or not, and shows the reply. Nothing is spoken or saved.
